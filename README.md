## Функциональные требования (ФР)

1. Управление товарами - продавцы могут создавать, изменять, удалять товары с названием, описанием, ценой, изображениями, наличием на складе
2. Категории товаров - иерархическая структура категорий, каждый товар связан с одной основной категорией
3. Поиск и фильтрация - полнотекстовый поиск по названию/описанию, фильтрация по цене, рейтингу, категории, доступности
4. Управление пользователями - регистрация, вход, профили покупателей и продавцов с разными правами доступа
5. Корзина и оформление заказа - добавление товаров в корзину, редактирование количества, оформление заказа с адресом доставки
6. Управление заказами - история заказов, отслеживание статуса (новый → подтвержден → отправлен → доставлен/отменен), отмена заказов
7. Система рейтингов и отзывов - оценки (1-5) и текстовые отзывы на товары, видны только после покупки
8. Расчет корзины - автоматический расчет суммы, налогов, скидок, валидация наличия товара в момент покупки
9. Управление каталогом продавца - продавец видит только свои товары, базовую аналитику (объем продаж, выручка)
10. Wishlist - сохранение избранных товаров пользователем, перемещение в корзину одним кликом

## Нефункциональные требования (НФР)

1. Аутентификация и авторизация - JWT токены, защита эндпоинтов по ролям (пользователь, продавец, админ)
2. Производительность - время ответа API < 500ms (p95) при 100+ RPS
3. Масштабируемость - stateless сервер, готовность к горизонтальному масштабированию
4. Надежность - аптайм ≥ 99.5%, идемпотентные операции, откат неудачных транзакций
5. Валидация данных - входная валидация всех полей, обработка ошибок с информативными сообщениями (код + текст)
6. Логирование - логирование критических операций (покупки, платежи, ошибки) в структурированном виде (JSON)
7. Безопасность - хеширование паролей (bcrypt), защита от SQL injection (ORM), HTTPS, rate limiting на эндпоинты
8. API документация - OpenAPI/Swagger спецификация, автоматическая генерация документов
9. Версионирование API - поддержка версий (/v1/, /v2/) для обратной совместимости
10. Тестирование - unit тесты для бизнес-логики (≥ 80% покрытие), интеграционные тесты, CI/CD пайплайн
